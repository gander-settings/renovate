# `forks`

Modifier. Turns on `forkProcessing`, so Renovate also runs in forks.

```json
{
  "$schema": "https://docs.renovatebot.com/renovate-schema.json",
  "extends": [
    "github>gander-settings/renovate",
    "github>gander-settings/renovate:forks"
  ]
}
```
